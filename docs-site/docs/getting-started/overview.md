---
title: Getting Started Overview
---

Choose the runtime surface that matches your app:

1. **Rust crate** for native embedding and full engine surface.
2. **JS/TS SDK** for Node.js/Bun.
3. **Tauri + React** for desktop app bridging through `firelite_exec`.
4. **C-FFI** for direct ABI integration.
5. **Lazarus/Free Pascal** for Pascal applications.

Each platform guide includes install/build notes and a "hello world" write/read example.
